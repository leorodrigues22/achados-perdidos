# AchaIFSC simples

Esta versão NÃO usa Firebase nem login.

## Como funciona
- A pessoa publica um objeto perdido ou encontrado.
- O anúncio fica salvo no `localStorage` do navegador.
- Atualizar ou fechar a página não apaga os anúncios.
- A página "Meus anúncios" permite marcar como resolvido ou excluir os anúncios criados naquele navegador.

## Importante
Os anúncios ficam salvos apenas no navegador/dispositivo onde foram publicados.
Se outra pessoa abrir o site em outro celular ou computador, ela não verá esses anúncios.

Para compartilhar os mesmos anúncios entre todos os usuários, futuramente será necessário usar um banco de dados online.
